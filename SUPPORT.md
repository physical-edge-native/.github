# Getting help

| You want to | Go to |
|---|---|
| ask a question about using a project, or share an idea or something you built | [GitHub Discussions](https://github.com/physical-edge-native/dyne/discussions) (Q&A, Ideas, Show and tell) |
| discuss the architecture itself (its assumptions, principles and limits) | [organization Discussions](https://github.com/orgs/physical-edge-native/discussions) |
| chat, ask for help, or find people to work with | [Discord](https://discord.gg/DuP494hVNX) |
| report a bug | an Issue in the repository where the bug is |
| report a security problem | private vulnerability reporting, see [SECURITY.md](SECURITY.md) |

English and Japanese are both welcome. The projects are maintained by one person, so replies may take a few days.
